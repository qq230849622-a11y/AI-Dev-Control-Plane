# Code of Conduct

We want AI Dev Control Plane to be a respectful, technically rigorous community.

## Expected behavior

- Be constructive, specific, and respectful.
- Assume good faith while testing claims with evidence.
- Welcome different backgrounds and experience levels.
- Protect private data and credentials.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, credential disclosure, malicious
interference, and deliberately deceptive reports are not acceptable.

Project maintainers may edit, close, or restrict participation in discussions
that violate this policy. Contact the repository owner through GitHub to report
conduct concerns.
