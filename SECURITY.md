# Security Policy

AI Dev Control Plane handles task envelopes, repository identity, pull-request
state, and coding-agent execution boundaries. Treat validation and dispatch
bypasses as security issues.

## Supported versions

Only the default branch and the latest published release receive security fixes.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue. Use GitHub's
private vulnerability reporting or contact the repository owner through the
public GitHub profile. Include:

- affected version or commit;
- reproducible steps or a minimal proof of concept;
- impact and affected trust boundary;
- any proposed mitigation.

You should receive an acknowledgement when the report is reviewed. Please allow
reasonable time for investigation and coordinated disclosure.

## Safe-harbor expectations

Security research is welcome when it avoids privacy violations, service
disruption, credential access, and modification of data belonging to others.
